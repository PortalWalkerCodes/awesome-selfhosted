## 🌟 What is Self-Hosting?

Self-hosting is the practice of hosting and managing applications on your own servers instead of relying on third-party providers ([SaaSS](https://www.gnu.org/philosophy/who-does-that-server-really-serve.html)). It allows you to:

- Gain full control over your data and privacy.
- Customize and optimize applications to your needs.
- Reduce reliance on external services and avoid vendor lock-in.

This repository is a **curated list of Free and Open Source Software (FOSS)** that you can self-host.

📌 **Recommended:** [HTML version](https://awesome-selfhosted.net/) | **Legacy:** [Markdown version](https://github.com/awesome-selfhosted/awesome-selfhosted)

## 🤔 Why Self-Host?

### 🔐 Privacy & Security

- Keep your data under your control.
- Avoid third-party data collection.

### 💰 Cost-Effective

- Save money on subscriptions by running services on your own hardware.

### 🚀 Performance & Customization

- Optimize for speed and tailor services to your needs.

## 🛠️ Software Categories

### 📊 Analytics

- **[Matomo](https://matomo.org/)** – Google Analytics alternative that respects privacy.
- **[GoAccess](https://goaccess.io/)** – Real-time log analyzer for web traffic.

### ⚙️ Automation

- **[Huginn](https://github.com/huginn/huginn)** – Automate tasks and workflows.
- **[Node-RED](https://nodered.org/)** – Flow-based programming tool for IoT.

### 💾 Backup

- **[BorgBackup](https://www.borgbackup.org/)** – Secure, efficient, deduplicating backups.
- **[Restic](https://restic.net/)** – Fast, encrypted backups with ease.

### ✍️ Blogging Platforms

- **[Ghost](https://ghost.org/)** – Modern, minimalist publishing platform.
- **[WriteFreely](https://writefreely.org/)** – Simple, privacy-focused blogging.

### 🗨️ Communication

#### 📧 Email

- **[Mail-in-a-Box](https://mailinabox.email/)** – Simple, full-featured mail server.
- **[Postfix](http://www.postfix.org/)** – Secure, high-performance mail transfer agent.

#### 💬 Chat & Messaging

- **[Rocket.Chat](https://rocket.chat/)** – Open-source Slack alternative.
- **[Zulip](https://zulip.org/)** – Threaded team chat for better collaboration.

### 📁 File Management

- **[Nextcloud](https://nextcloud.com/)** – Self-hosted cloud storage and collaboration.
- **[Seafile](https://www.seafile.com/)** – High-performance file syncing and sharing.

### 🎬 Media Streaming

- **[Jellyfin](https://jellyfin.org/)** – Self-hosted alternative to Plex.
- **[Navidrome](https://www.navidrome.org/)** – Lightweight music streaming server.

### 🛡️ Security & Privacy

- **[Pi-hole](https://pi-hole.net/)** – Network-wide ad blocker.
- **[WireGuard](https://www.wireguard.com/)** – Fast, secure VPN protocol.

### 🌐 Web Hosting & Development

- **[Caddy](https://caddyserver.com/)** – Simple, automatic HTTPS web server.
- **[OpenLiteSpeed](https://openlitespeed.org/)** – High-performance web server.
